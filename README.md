# National Chengchi University Northern California Alumni Foundation

Official website for the National Chengchi University Northern California Alumni Foundation.

The site shares the Foundation's mission, activities and events, leadership team, photo archive, alonng with and donation instructions.

## Pages

- `index.html` — Home page featured activities, donation details, and contact information
- `events.html` — Subpage with educational, cultural, and scholarship activities
- `team.html` — Subpage introducing Board of Directors, Directors, and Officers templates
- `gallery.html` — Photo gallery

## Local preview

 This is a static HTML, CSS, and JavaScript website. For local view: 

```bash
npm start
```
